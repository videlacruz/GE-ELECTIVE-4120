
# ACTIVITY 7
## Resume Generating

### Description

This activity focuses on using and comparing different Large Language Models (LLMs), specifically Claude AI and ChatGPT, to generate a professional one-page resume. It involves providing both AI tools with the same personal information, educational background, certifications, and career objectives to evaluate how they organize, present, and improve resume content. The activity was completed as part of the requirements for GE-ELECTIVE-4120.

### Objectives

- Understand the main concepts discussed in the activity.
- Apply the knowledge and skills gained during the lesson.
- Complete the required outputs and demonstrate learning.

### Learning Reflection

**What Have I Learned?**

hrough this activity, I learned how to use different AI tools to create a professional resume and improve the way personal information, educational qualifications, and certifications are presented. I also developed a better understanding of how different Large Language Models interpret the same prompt and produce different outputs in terms of content, structure, clarity, and formatting.

One challenge I encountered was determining which AI-generated resume was more appropriate for a professional nursing application, especially since I do not yet have formal work experience. I addressed this by comparing the outputs of Claude AI and ChatGPT and identifying which details best highlighted my nursing education, clinical exposure, and certifications.

In the future, I can apply what I learned by using AI tools to prepare professional documents, improve my resume, and organize information for future job applications. As an aspiring nurse, I can use these skills when preparing for employment opportunities in healthcare. I also hope to improve my skills by exploring other AI tools and learning how to create more effective prompts to achieve better and more accurate results.
