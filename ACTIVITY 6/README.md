
# ACTIVITY 6
## Making a website

### Description

This activity focuses on developing a personalized and interactive digital gift website using React, JavaScript, HTML, and CSS with the assistance of Replit AI. The project, entitled "A Surprise for You," features a Snoopy and Spider-Man-inspired theme with interactive buttons, animated elements, pop-up messages, thoughtful reminders, and a personalized letter. It aims to demonstrate how web development and AI-assisted tools can be used to create an engaging and meaningful user experience. The activity was completed as part of the requirements for GE-ELECTIVE-4120.

### Objectives

- Understand the main concepts discussed in the activity.
- Apply the knowledge and skills gained during the lesson.
- Complete the required outputs and demonstrate learning.

### Learning Reflection

**What Have I Learned?**

Through this activity, I learned how to use Replit AI to develop an interactive website by providing specific prompts and instructions. I also gained a better understanding of how React, JavaScript, HTML, and CSS work together to create website layouts, interactive buttons, pop-up messages, and animations. I realized that AI tools can help turn creative ideas into functional digital projects, even when developing more personalized designs.

One challenge I encountered was translating my ideas into a website that looked the way I imagined while making sure that all the interactive features worked properly. I addressed this by improving my prompts, specifying the design elements and website functions I wanted, and refining the generated output to achieve the desired result.

In the future, I can apply what I learned by creating other interactive websites, personal projects, and digital presentations. I can also use AI-assisted development tools to improve my programming skills, explore different website designs, and make my projects more creative and user-friendly. Most importantly, this activity taught me that technology can be used not only for academic and professional purposes but also to express creativity and create something meaningful for others.
